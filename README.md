# 浮幕 · FloatScreen

Windows 游戏攻略悬浮浏览器与桌面弹幕投影工具。

## 功能

- 通过 WebView2 打开攻略网页，支持置顶、拖动、缩放和视频快捷控制。
- 沉浸模式隐藏软件标题栏和工具栏，包含鼠标穿透和跟随鼠标的透明圆洞。
- 记住窗口位置、大小、网页缩放和显示设置。
- 地址栏右侧提供历史记录按钮，支持搜索、重新打开、复制链接、删除和清空。
- 地址栏右侧直接提供“收藏列表”和“收藏此页”；收藏列表支持搜索标题或地址。
- 原创软件图标，简洁工具栏与统一的辅助窗口样式。
- 收藏网页，支持键盘、中键、侧键和滚轮快捷键录入。
- 读取 B站 BV 视频的文字弹幕，在所选显示器上方投影。
- 横向范围以屏幕中线为中心，默认左右各 400 屏幕像素；纵向默认上方 33%。
- 可调整字号、不透明度、滚动耗时、密度、颜色、描边和重复合并窗口。
- 规则去重：统一全半角、大小写、空格和标点，压缩整句重复，支持用户编辑别名规则表。

## 下载与运行

在 [GitHub Releases](https://github.com/nineocean9/FloatScreen/releases) 下载 Windows x64 ZIP，完整解压后运行 `FloatScreen.exe`。
输入网页链接后按 Enter 打开，地址栏右侧依次是历史、收藏列表、收藏此页、置顶和更多。
“收藏此页”高亮表示当前网页已收藏，删除可在收藏列表中操作。

需要：

- Windows 10/11 x64。
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)。
- [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

发行包依赖系统运行时，不包含完整 .NET 或浏览器运行时，也尚未进行代码签名。

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 播放／暂停 | Ctrl + Alt + Space |
| 向后／向前跳转 | Ctrl + Alt + Left / Right |
| 隐藏／显示窗口 | Ctrl + Alt + H |
| 开关沉浸模式 | Ctrl + Alt + F10 |
| 开关弹幕投影 | Ctrl + Alt + D |

在“更多 → 设置 → 播放器与快捷键”中点击快捷键框，然后按键或操作鼠标，保存后生效。
快捷键冲突会提示，启动时不会因单个冲突撤销其余可用快捷键。
沉浸模式下可通过快捷键或托盘菜单恢复普通窗口。

## 弹幕投影与规则表

打开 B站 BV 视频并开始播放，通过菜单、托盘或快捷键开启弹幕投影。
投影默认关闭；菜单会显示当前开关状态及读取数量或失败原因。

“设置 → 弹幕投影”控制显示器、区域高度、显示半径、字号、不透明度和滚动耗时等。
滚动耗时越小越快，不透明度越小越透明。所有弹幕都限制在设置的投影区域内。

“设置 → 去重规则表”支持添加、修改、删除规则，例如：

| 原写法 | 统一词 |
|---|---|
| biaoji | 标记 |
| 标注 | 标记 |

匹配前先做格式与重复归一化，所以 `标记`、`标记标记标记`、`BIAOJI`、`biao ji` 可以归入同一组。
纯数字不做重复压缩，`标记1` 与 `标记` 保持区别。规则最多 200 条，保存时检查冲突和循环。
可以删除默认别名规则；格式归一化和整句重复压缩仍保留。

同组弹幕在默认 5 个视频秒内合并，保留首条原文和样式，显示 `文字 ×数量`。
数量统计弹幕条数，一条文字重复三遍仍算一条。暂停时冻结，跳转后清空并重新调度。
规则只在读取或修改规则时生成合并键，动画帧循环使用字典查询。

## 历史记录

点击地址栏右侧“历史”按钮，或托盘菜单中的“历史记录”。
自动保存成功访问的网页标题、地址和时间，包含站内切换、刷新、返回和重新打开。
同一页面的标题更新和锚点变化不会新增访问记录，加载失败的网页不会记入历史。

记录按最近访问排序，可搜索标题和地址，双击或按 Enter 打开。
支持复制链接、多选删除（也可按 Delete）和确认后清空全部历史。
数据保存在用户目录的 `history.json`，即时保存并在重启后恢复，最多保留最近 10,000 条。
安装此功能之前的访问记录无法补回；自动恢复的上次网页会在本次成功打开后记入历史。
删除历史不会删除收藏、网页登录状态，也不会修改启动时恢复的最后一个链接。

历史、设置和收藏使用非模态窗口，可同时打开，主窗口仍能操作。
重复点击同一个入口会唤回已有窗口，保留未保存的设置内容。
这些窗口跟随主窗口置顶；编辑时暂时停用全局快捷键，切回主窗口或其他应用后恢复。

## 数据与边界

设置、收藏、历史记录和独立浏览器数据位于 `%LOCALAPPDATA%\FloatScreen`。
首次运行会尝试迁移此前本地轻量版的设置和收藏，保留旧文件；不迁移浏览器缓存和登录状态。

- 弹幕来自站点当前可访问的 XML 弹幕池，数量可能与网页智能筛选结果不同。
- 支持普通滚动、顶部固定、底部固定文本弹幕；不支持直播、图片及高级特效弹幕。
- 隐藏或最小化播放器时投影同步收起；辅助窗口获得焦点时暂时收起，切走后恢复。
- 读取失败只影响投影，原播放器继续工作。
- 桌面叠加以窗口化、无边框全屏游戏为目标，独占全屏不保证覆盖。
- 网络接口变化、显示缩放和游戏环境仍需实际验收。

## 构建

在工程根目录执行：

```powershell
dotnet restore src/FloatScreen.csproj --locked-mode
dotnet build src/FloatScreen.csproj -c Release --no-restore
dotnet publish src/FloatScreen.csproj -c Release -r win-x64 --self-contained false -o release
```

GitHub Actions 执行构建检查。首次发行完成本机构建和针对既有故障的定点诊断，未进行完整跨设备测试。

`tests` 保留本地基础与浏览器验收工具，使用独立配置目录；`--ui` 会运行屏幕外窗口并生成渲染图。
测试视频是自制的短 WebM 样本。

图标的矢量源位于 `src/Assets/FloatScreen.svg`，ICO 已提交在源码中。
需要重新生成时，在 Windows PowerShell 5.1 运行 `powershell.exe -NoProfile -File tools/generate-icon.ps1`。

```powershell
dotnet run --project tests/FloatScreen.Tests.csproj -c Release
dotnet run --project tests/FloatScreen.Tests.csproj -c Release -- --ui
```
